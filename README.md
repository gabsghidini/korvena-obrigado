# Korvena — Página de Obrigado

Landing page de obrigado (pós-conversão) da Korvena. Redireciona o visitante direto para o WhatsApp `+55 11 93051-3360`.

## Conteúdo

- `index.html`: página completa, self-contained (HTML + CSS inline). Única dependência externa é o Google Fonts (Unbounded, Manrope, IBM Plex Mono).

## Deploy

Arquivo estático puro, pode ser publicado em qualquer host (Vercel, Netlify, GitHub Pages) apontando para a raiz do repositório, sem build step.

Sugestão de rota no site principal: `korvena.com.br/obrigado`.
